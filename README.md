# 🌴 Hawaiʻi Climate Explorer — Frontend

This is the Streamlit frontend for [Hawaiʻi Climate Explorer](https://github.com/Untrained-Parameters/hi-climate-app), a visual, interactive web app for exploring climate data across the Hawaiian Islands.

For setup, environment configuration, and instructions on running the full app (with or without Docker), see the [main repository README](https://github.com/Untrained-Parameters/hi-climate-app#readme).
